# Clonar repositorio
Para clonarlo usando GIT puedes hacerlo con este comando: git clone https://github.com/ChristianJairCH/rgbif.git
O puedes dascargar el proyecto como ZIP: haz clic en el botón verde Code → Download ZIP.
Abrir el proyecto en RStudio (.Rproj).
Restaurar el entorno con: renv::restore()
